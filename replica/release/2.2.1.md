# Keepsake 2.2.1

Everything in 2.2.0 (see 2.2.0.md), plus:

## New

- **A new app icon: four pastel scraps, the big one terracotta with a cream bookmark tag** (the
  "Patchwork" icon, picked Oct 22 2026). It is the app's own icon on iPhone and iPad (light, dark and
  tinted home screens), the Safari for Mac app, and the Chrome and Safari toolbar button (light and
  dark). At toolbar sizes it sits straight with thicker lines so it stays readable at 16 px.
- The Pantry Pop logo beside "Keepsake" in the dashboard sidebar and the toolbar popup shows the same
  four scraps. The other styles keep their bookmark logo.
- In the icon pickers (Chrome Settings → Appearance, iOS Appearance, the Mac app) the default icon is
  now called "Keepsake". The Field Notebook, Gallery, Night Atlas and Swiss Index icons are unchanged.

The app is still called Keepsake; no store name, bundle id or URL changed.

## Store art

Rebuilt listing icon, promo tiles, screenshots and the App Store 1024 icon:
`/mnt/project-files/keepsake/store-branding-patchwork/` (tools/ re-renders them).

- `npm test`, `npm run test:ios-core`
- The art is regenerated with `node tools/icons/make-style-icons.mjs pantry` and matches the approved
  final set pixel for pixel; iOS 1024 icons have no alpha channel.
