# Bowerbird 2.2.1 (formerly Keepsake)

Everything in 2.2.0 (see 2.2.0.md), plus:

## New

- **Keepsake is now Bowerbird.** The name changes everywhere people see it: the Chrome Web Store
  listing and toolbar ("Save to Bowerbird"), the right-click menu, the dashboard and popup, the in-page
  save card, the iPhone and iPad home screen, share sheet and widgets, and the Safari for Mac app (now
  Bowerbird.app, extension "Bowerbird Extension"). Exports are named bowerbird-export-DATE.json.

- **A new app icon: four pastel scraps, the big one terracotta with a cream bookmark tag** (picked
  Oct 22 2026). It is the app's own icon on iPhone and iPad (light, dark and
  tinted home screens), the Safari for Mac app, and the Chrome and Safari toolbar button (light and
  dark). At toolbar sizes and the Mac's 16/32 px sizes it sits straight with thicker lines so it stays
  readable.
- The Pantry Pop logo beside the name in the dashboard sidebar and the toolbar popup shows the same
  four scraps. The other styles keep their bookmark logo.
- In the icon pickers (Chrome Settings → Appearance, iOS Appearance, the Mac app) the default icon is
  now called "Bowerbird". The Field Notebook, Gallery, Night Atlas and Swiss Index icons are unchanged.

The app is still called Keepsake; no store name, bundle id or URL changed.

## What did not change (so nothing is lost)

- Your library, settings and AI key: storage names, the IndexedDB database and the iOS App Group stay
  the same, so updating keeps everything.
- Store identity: the Chrome extension id, the bundle ids (com.harrisonfischberg.keepsake…), the
  keepsake:// link scheme and the export format marker (`keepsake-export`, so old exports still
  import). Xcode project, scheme and target names and the repo folder names are unchanged too.
- Old links: rarecreatures.app/apps/keepsake/ redirects to /apps/bowerbird/.

## Other

- Home's title row stacks the buttons under the name at the largest accessibility text sizes.
