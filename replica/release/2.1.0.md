# Keepsake 2.1.0

## New

- **The toolbar icon never saves on its own.** Clicking it opens a popup with Open dashboard at the top
  and the iPhone share sheet's "Where does it live?": pick a collection, a Lifestyle view, or "Not sure?
  Put it in Review", rename the title if you like, add a note, then Save. The on-page button and the
  right-click menu still save straight away.
- **AI works out products from their picture.** For a save that is something to buy, the AI reads the
  picture as well as the post's words (which may be wrong), uses its own web search to find the product's
  page, and Keepsake reads that page's product data. The card shows the shop's name, price, description
  and specs, with the AI's own summary labelled *AI summary*. Everything it changes is in the change log
  with Undo.
- **Pick the Claude model and effort.** Settings → AI offers Claude Haiku 5.5 (default), Sonnet 5.5,
  Opus 5.5 and Fable 5.1, and an effort level (Low, Medium by default, High). New installs start on
  Anthropic; an existing provider choice is kept.
- **Remove goal, with Undo.** "End goal" on a workout goal is now "Remove goal", and a toast lets you
  take it back.

## Privacy and data

- PRIVACY.md describes the new product request (picture, web search by the provider, one product page
  read only on sites you already let Keepsake read, without cookies) and the stored effort level.
  The website privacy page needs the same update.
