# Keepsake 2.0.2

## New

- **Grant access to instagram.com from Keepsake itself.** Settings → Instagram import → "instagram.com
  access" now has a Grant access button that asks the browser for the site. If the prompt is declined
  (or Safari doesn't show one), Keepsake says where to allow it by hand, and the row updates as soon as
  access changes, including from the browser's own settings.
- The popup on your Instagram Saved page shows the same ask, with a Grant access link, before
  "Import all collections" while access is missing.

## Fixed

- Safari: access granted in Safari → Settings → Extensions → Edit Websites now counts, even when
  Safari doesn't list the site among the extension's permissions.

## Privacy and data

- No change. instagram.com access stays optional and is only asked for when you click.
