# Keepsake 2.0.0

1.4.5 was uploaded but its publish was cancelled so the new look could ship with it, so 2.0.0 is the first
release after 1.4.4 and includes everything in `1.4.5.md` as well.

## What's new

- **A new look: Pantry Pop.** The default style on Chrome, Safari, iPhone, iPad and the Mac app: thick ink
  outlines, hard shadows that squash when pressed, and one bright colour per kind. Saves without a photo
  become jar labels in their kind's colour.
- **Four more styles** to choose in Settings → Appearance: Field Notebook, Gallery, Night Atlas and Swiss
  Index, each in light and dark. Older style settings (Modern, Moss, Minimalist) move to Pantry Pop.
- **Pick your toolbar icon.** Felt pocket stays the default; each style has its own.
- **Import all your Instagram Saved collections at once** (see `1.4.5.md`): on your Saved page, the popup
  opens each collection in turn, then "All posts". Each Instagram collection becomes a group with the
  same name, or Keepsake sorts them. Export JSON and AirDrop the file to Keepsake on iPhone.

## Privacy

- No change beyond 1.4.5: `PRIVACY.md` describes Import all collections. The copy at
  https://rarecreatures.app/apps/keepsake/privacy/ needs that section too.

## Data

- The style setting takes the new ids (pantry, notebook, gallery, atlas, swiss); old ids read as pantry.
  Fonts are bundled in the extension (OFL). Nothing to migrate.
