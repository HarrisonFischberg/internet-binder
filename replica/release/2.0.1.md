- **Instagram import found 0 posts and spun on "Looking for posts…" for ever** (one collection and
  Import all collections), seen in Safari without instagram.com access. Safari leaves the tab's address
  out of the scan's messages then, and Keepsake dropped every one. Reports from the tab the scan was
  started in now count; any message with an address must still come from instagram.com.
- If a scan still never reports, the popup says so after 15 seconds, with where to allow instagram.com,
  instead of spinning.
