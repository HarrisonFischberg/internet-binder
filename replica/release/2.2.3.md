# Internet Binder 2.2.3

Everything in 2.2.2, plus:

## iPhone and iPad

- **The share sheet stays open.** It no longer tidies the whole library when it opens, which made iOS
  close it for using too much memory, so it flashed and vanished on every share. (PR #47)
- **Find a collection.** The share sheet's Collections page has a search field. If nothing matches,
  the New tile takes what you typed as its name. (PR #48)
- **New collection everywhere you pick one:** in every Move to… menu (a save's ⋯ menu, long press,
  bulk Select), in Review's Another collection… and in a save's Where does it go?. (PR #48)

## Chrome and Safari

- **Find a collection** in the toolbar popup, the same as on iPhone. (PR #48)
- **＋ New collection…** in the edit dialog and in tab import. (PR #48)

## Build

- TestFlight build 7 for iOS and Mac (CURRENT_PROJECT_VERSION 7, MARKETING_VERSION 2.2.3).
