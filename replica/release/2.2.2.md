# Internet Binder 2.2.2

Everything in 2.2.1 (see 2.2.1.md), plus:

## iPhone and iPad

- **Home opens ready.** Recent saves and the counts on Home are there in the first frame instead of
  popping in a moment later. The app reads a small summary of the library straight away
  (`Library.glance()`) and shows it until the full library has loaded; with very large libraries
  (tested with 15,000 saves) the difference is easy to see. (PR #41)

- **Places › Review rows open the save.** Tapping a row's picture or name opens that save; underneath
  are **Open post** (Instagram) or **Open website**, then **Read again** and **Fix**. (PR #42)

## Chrome and Safari (in the code; Chrome is not being released with this version)

- **Places found on the map automatically.** Opening Places looks up every place without a pin on its
  own (OpenStreetMap Lookup only, no AI, one request a second), shows "Finding places on the map… n of N",
  and lists the ones it couldn't find. A place that wasn't found isn't searched again until its name or
  address changes. The "Look them up" button is gone and the privacy page says so. (PR #42)

## App Store

- A made-up demo library (`ios/demo/store-demo.json`, invented names and original art) and the UI test
  `ScreenshotTests.testStoreScreens` that shoots the App Store screenshots from it. Nothing in the app
  changes for people using it. (PR #40)

## Build

  released with this version.
