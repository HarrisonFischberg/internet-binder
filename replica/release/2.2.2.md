# Internet Binder 2.2.2

Everything in 2.2.1 (see 2.2.1.md), plus:

## iPhone and iPad

- **Home opens ready.** Recent saves and the counts on Home are there in the first frame instead of
  popping in a moment later. The app reads a small summary of the library straight away
  (`Library.glance()`) and shows it until the full library has loaded; with very large libraries
  (tested with 15,000 saves) the difference is easy to see. (PR #41)

## App Store

- A made-up demo library (`ios/demo/store-demo.json`, invented names and original art) and the UI test
  `ScreenshotTests.testStoreScreens` that shoots the App Store screenshots from it. Nothing in the app
  changes for people using it. (PR #40)

## Build

- TestFlight build 5 (CURRENT_PROJECT_VERSION 5, MARKETING_VERSION 2.2.2). Chrome is not being
  released with this version.

## Checked before tagging

- `npm test`, `npm run test:ios-core`
- `node ios/tools/bundle-core.mjs` (no shared-code changes) and `python3 ios/tools/make-xcodeproj.py`
  after the version bump
- iOS Release build for a device on Harold's Mac
